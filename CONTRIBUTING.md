# Contributing to Codex PR Sentinel

Thank you for helping make open-source maintenance faster and safer!

## Development Workflow
1. Fork the repository and create your feature branch (`git checkout -b feat/new-rule`).
2. Add unit tests in `tests/test_scanner.py` for any new static rules or CLI flags.
3. Run the test suite locally: `python -m unittest discover -s tests`.
4. Open a Pull Request with a clear description of the problem and solution.
